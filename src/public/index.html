How Laya works

Laya reads your context and evaluates the possibilities you define. Every run is independent; previous messages are not added to its context.

Bool · Yes or no
Returns the probability of true using Laya’s noul type. Edit the descriptions of both sides to define what counts. A 50% split is shown as a tie.
Choice · Pick one
Returns one label and a probability for each option. Labels should be distinct and descriptions should explain when they apply.
Ranking · Compare alternatives
Uses a choice distribution, displayed from highest to lowest probability. The probabilities compare these options with each other; they are not independent quality scores.

Make the input count

Provide relevant facts, not just a question. Keep labels short and options few. The published default context is 1,024 tokens for Typed Decisions and 512 for English, including the question and options. Longer inputs may be truncated by the runtime. Character counts are not token counts.

Confidence describes how concentrated the distribution is. It does not measure the chance of being correct. Validate decisions on your own examples; the English checkpoint can be sensitive to boolean wording.

Context from files

Use Add files below Context to read PDF, Word (.docx/.doc), Markdown, text, and Excel (.xlsx/.xls/.xlsm/.csv) files locally. Review and edit the extracted text, then append it or replace Context. The extracted text is included when you save JSON or Excel. PDF images need OCR first; spreadsheet formulas use saved values and are not recalculated. Imports accept up to 5 files, 10 MB each, with 200 pages per PDF and 200,000 extracted characters per file. Trim long previews to fit the 24,000-character Context field and the selected model's smaller token budget.

Save and resume

Save JSON stores every decision in this conversation plus your current setup. Load JSON restores them so you can continue adding decisions. Export Excel creates a workbook with decisions, probabilities, and the current setup. Each model request still uses the context you explicitly supply.

Your workspace

Only the two requested models are available. Recent decisions stay in this window only (up to 40 runs). Closing Laya offers Save JSON, Save Excel, Save Both, Discard, or Cancel. The conversation clears on exit; use Load JSON to resume a saved conversation. JSON export includes your context and model response.
